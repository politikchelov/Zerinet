ZERINET — аниме-сайт: AniLibria + Kodik, аккаунты, профили, друзья, чат, «Критика», команды админов

ЗАПУСК (Windows)
1. Распакуй папку, поставь Python с python.org (галочка "Add to PATH").
2. Двойной клик по start.bat -> откроется http://localhost:8080
   (или в терминале в этой папке:  py server.py)

КАК СТАТЬ АДМИНОМ (любой из двух способов)
Способ 1 — файлом: зарегистрируйся на сайте, открой admins.txt (рядом с server.py) блокнотом, впиши свой ник
  отдельной строкой, сохрани и обнови страницу сайта. Перезапускать сервер не нужно.
Способ 2 — командой: запусти make_admin.bat — он покажет список зарегистрированных, впиши свой ник.
Админов выдаёт только тот, у кого есть доступ к папке сайта, через сайт стать админом нельзя.
После этого в чате работают команды, набери /help.

ЧТО ЕСТЬ НА САЙТЕ
- Главная: баннер с новинками, «Продолжить просмотр», избранное, ряды и каталог с кнопкой «Показать ещё».
- 🎨 в шапке меняет цветовую тему (Фиолет, Сакура, Океан, Закат, Матча), 🎲 открывает случайное аниме.
- Оформление: живой фон, 3D-наклон карточек, баннер с полоской прогресса, полоса загрузки сверху, свечение у плеера.
- ♡ В избранное на странице аниме (хранится в браузере). История просмотра тоже.
- Профиль (#/user/ник): аватарка (загружаешь любую картинку, сайт сам обрежет), "о себе", друзья.
- Друзья: заявки, принять/отклонить, поиск людей, кто в сети.
- Очки и ранги: выдают ТОЛЬКО админы. Ранг даёт рамку вокруг аватарки:
  Новичок, Зритель (бронза), Знаток (серебро), Легенда (золото), Модератор (зелёная), Админ (фиолетовая).
- Чат (общий для всех), Топ по очкам.
- Критика: блок прямо под плеером на странице каждого аниме (кнопка 💬 Критика в шапке страницы ведёт к нему).
- Источники видео: AniLibria и Kodik (Kodik включается, если есть kodik_token.txt).
  Если Kodik пишет «HTTP 401» — Kodik не принял токен: проверь файл kodik_token.txt (один токен, без лишних слов)
  и открой в браузере https://kodik-api.com/search?token=ТВОЙ_ТОКЕН&title=naruto — должен прийти список, а не ошибка.
  В консоли, где запущен server.py, при такой ошибке пишется ответ Kodik.
- Внизу сайта ссылка «Проверка соединения» — отчёт, что работает, а что нет (можно скопировать и прислать).

СОВМЕСТНЫЙ ПРОСМОТР
- На странице аниме нажми «👥 Смотреть вместе» -> откроется комната и появится ссылка (кнопка «Скопировать ссылку»).
- Друзья открывают ссылку (нужен аккаунт на сайте) и попадают в ту же серию: пауза, перемотка и смена серии
  синхронны у всех. По умолчанию управляет только хост, кнопка «Управление: только я / все» разрешает всем.
- В комнате есть список зрителей и свой чат. Если браузер не даёт запустить видео сам — нажми «Присоединиться к просмотру».
- Работает с источником AniLibria (плеер Kodik закрытый, его синхронизировать нельзя).
- Комнаты живут в памяти сервера: после перезапуска server.py они пропадают. Комната закрывается через 6 часов без активности.
- Проверить самому: открой сайт в двух окнах — обычном и в режиме инкогнито (в инкогнито другой аккаунт).
- Позвать друзей прямо с твоего компьютера, пока сайт не на хостинге: запусти в соседнем окне
  cloudflared tunnel --url http://localhost:8080  (бесплатная утилита cloudflared с cloudflare.com) —
  она выдаст публичную https-ссылку. И запускай сайт так:  set TRUST_PROXY=1  и потом  py server.py

КОМАНДЫ АДМИНОВ (пишутся в чате)
/help                    список команд
/ranks                   список рангов
/userinfo ник            данные игрока
/points ник +50          добавить очки (минус — забрать)
/setpoints ник 100       поставить очки
/rank ник легенда        выдать ранг (рамка у аватарки)
/mute ник 30             заглушить на 30 минут;  /unmute ник
/ban ник причина         заблокировать;  /unban ник
/del 15                  удалить сообщение чата №15 (номер виден админам рядом с сообщением)
/delc 7                  удалить комментарий в «Критике» №7
/clear 50                удалить последние 50 сообщений чата;  /clear all — все
/announce текст          объявление в чат
Админы также видят кнопку ✕ у сообщений и комментариев.

ГДЕ ЛЕЖАТ ДАННЫЕ
Папка data/ рядом с server.py: база zerinet.db и аватарки. Для копии просто скопируй эту папку.
Токен Kodik — в kodik_token.txt. Эти файлы НЕ загружай на GitHub (они в .gitignore).

БЕЗОПАСНОСТЬ (что уже сделано)
Пароли хранятся хешем (scrypt), вход по защищённой cookie, лимиты на частоту (регистрация, вход, чат, комментарии),
запрет менять очки и ранг через сайт, наружу отдаются только index.html и social.js (токен и база недоступны по адресу).

ВЫЛОЖИТЬ В ИНТЕРНЕТ
Vercel для этой версии НЕ подходит: ему нужен постоянный диск для базы и аватарок, а Vercel их не хранит.
Нужен хостинг, где можно запустить Python и хранить файлы: VPS, либо Render/Railway с подключённым диском.
Запуск там:  HOST=0.0.0.0 TRUST_PROXY=1 py server.py  (за HTTPS-прокси вроде Caddy), токен — переменная KODIK_TOKEN.
(vercel.json и папка api остались от старой версии без аккаунтов, можно удалить.)
